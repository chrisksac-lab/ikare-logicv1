# iKare Logic

Backend services and business logic powering the iKare healthcare ecosystem.

## Overview

iKare Logic is the central backend platform responsible for managing patient data, consultations, appointments, authentication, notifications, disease prediction integrations, and healthcare workflows.

It provides secure APIs consumed by the mobile application, web platform, and administrative dashboard.

## Features

- User authentication and authorization
- Patient profile management
- Doctor profile management
- Appointment scheduling
- Consultation management
- Real-time communication support
- Medical records management
- Notification services
- Disease prediction integrations
- Analytics and reporting support

## Technology Stack

- Node JS
- Mongo DB

## Architecture

The backend follows a modular architecture that separates:

- Authentication
- Patient Management
- Doctor Management
- Appointments
- Consultations
- Notifications
- Analytics

This structure allows independent scaling and maintainability.
